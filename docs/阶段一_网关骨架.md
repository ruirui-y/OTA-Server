# 第一阶段：网关骨架

## 目标

设备能连上来、能认证、能发心跳，服务端能说出「当前多少在线」。业务和数据库都还没有。

## 跑起来

服务端（Linux）：

```bash
cmake --preset linux-release
cmake --build --preset build-linux-release
./build/linux-release/bin/ota_server --listen 9500 --io 4
```

模拟器（Linux，建议放另一台机器）：

```bash
./build/linux-release/bin/ota_simulator --host 192.168.184.128 --port 9500 --count 1000
```

## 预期

服务端每 5 秒打印：

```
连接=1000 在线=1000
```

## 这一阶段刻意没做的

| 没做 | 为什么 |
|---|---|
| 查库认证 | 数据库第二阶段才接 |
| 心跳超时剔除 | 需要定时扫描，第二阶段做 |
| 指令下发、OTA | 需要业务服务，第三阶段 |
| Qt 控制台 | 先让服务端能自证 |
| 垂直扩展 / 分片 | 先摸清单机上限 |
